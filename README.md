# QR → Excel для Ozon

Небольшой сайт без сервера и базы данных. Позволяет загрузить PDF-файл со штрихкодами/QR-кодами товара и Excel-шаблон **«Состав грузомест»**, автоматически заменить значения столбца **«QR-код»** и скачать готовый `.xlsx`.

## Возможности

- Читает QR-коды в порядке страниц PDF. Для предоставленного PDF Ozon: от `ii50097774701` до `ii50097774748` (48 страниц).
- Находит столбец «QR-код» и лист по названию заголовка, а не только по буквам столбца.
- Перезаписывает только QR-коды в строках товаров. Оставляет остальные поля, стили и прочие листы исходного Excel.
- Если кодов больше, чем строк, показывает два варианта: заполнить только существующие строки или дополнить таблицу новыми строками. Для дополнения копирует данные последнего товара. Если товаров разных несколько, дополнение блокируется из-за риска неправильного состава поставки.
- Показывает предпросмотр и предупреждает о несовпадениях, пропущенных страницах и дубликатах кодов.
- Работает целиком в браузере: без отправки файлов на сервер, без регистрации и API-ключей.

## Как открыть локально

Для корректной работы JavaScript-модулей рекомендуем обычный локальный веб-сервер. Например, если установлен Python:

```bash
python -m http.server 8000
```

Затем открыть http://localhost:8000. Двойной щелчок по `index.html` (адрес `file://`) может блокировать JavaScript-модули в некоторых браузерах.

## Как выложить на GitHub Pages

1. Создайте новый **публичный** репозиторий на GitHub, например `ozon-qr-excel`.
2. Загрузите в его корень все файлы сайта: `index.html`, `app.js`, `pdf-extract.js`, `xlsx-fill.js`, `styles.css`, `favicon.svg` и папку `vendor/`.
3. Откройте **Settings → Pages** в репозитории.
4. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
5. Укажите ветку `main`, папку `/ (root)`, нажмите **Save**.
6. После публикации сайт будет открываться по адресу вида `https://ИМЯ_АККАУНТА.github.io/ozon-qr-excel/`.

Бэкенд, Docker, домен и платный хостинг не нужны. Файлы с этикетками и Excel не добавляйте в репозиторий: загружайте их уже на опубликованном сайте.

## Ограничения

- PDF должен содержать **выделяемый текст** с кодами формата `ii` + цифры (как в исходном примере Ozon). Это облегчённый PDF-парсер под этикетки Ozon; он не выполняет OCR, не умеет распознавать сканы и не гарантирует работу с любыми сторонними PDF/нестандартными объектными потоками PDF.
- Поддерживается `.xlsx`, а не старый `.xls`.
- Если кодов в PDF меньше, чем товарных строк в Excel, оставшиеся ячейки QR очищаются, чтобы не сохранять ошибочные старые коды. Нужно проверить состав поставки перед импортом в Ozon.
- При дополнении таблицы новые строки наследуют данные о товаре и грузоместе из **последней** строки. Этот режим безопасен только если дополнительные строки действительно представляют тот же товар и грузоместо.
- Для сложных Excel-шаблонов с таблицами, формулами, определёнными именами, объединениями в области добавляемых строк или сторонними макросами автоматическое добавление строк может быть недостаточным. Формат `.xlsm` не поддерживается.
- Для лучшей совместимости используйте свежий Chrome или Edge с `DecompressionStream`.

## Структура

```text
index.html            — страница с интерфейсом
styles.css            — оформление
app.js                — загрузка, предпросмотр и скачивание
pdf-extract.js        — локальное чтение кодов из PDF
xlsx-fill.js          — редактирование XLSX как ZIP/XML
favicon.svg           — иконка
vendor/jszip.min.js   — JSZip, включена для автономной работы
vendor/JSZIP-LICENSE.md
```

JSZip распространяется по лицензии MIT или GPLv3; файл лицензии приложен в `vendor/`.
